Support · IFC Asset Capture

How can we help?

Import IFC models, capture asset information, use QR labels and export reviewed evidence. Find quick guidance and contact details below.

Getting started

  1. Open IFC Asset Capture and choose Import IFC Model, or explicitly open the labelled demonstration project.
  2. Select a supported .ifc file from Files (iPhone/iPad) or the macOS file picker.
  3. Use Assets to search IFC GlobalIds, inspect original property sets and review maintainable asset candidates.
  4. Capture missing field information and photographs. Changes begin as drafts or pending evidence.
  5. Use Review to approve fields and photographs independently.
  6. Open Packages to export a reviewed ZIP including approved metadata and images.

Supported platforms and files

iPhone and iPad with iOS/iPadOS 18 or later; native macOS 15 or later. The current release supports IFC2X3 and IFC4 .ifc STEP files.

Import limit: 50,000,000 bytes (approximately 50 MB) per IFC file. Unsupported IFC schemas and malformed files may be rejected.

The app reads IFC data and does not modify the original IFC source file. It is not a 3D geometry viewer or an automatic COBie writer.

QR labels

Create individual PNG labels or A4 sheets from the selected IFC collection. Print at 100% / Actual Size, without Fit to Page, for reliable scanning.

The QR identifies a record in a specific model and source revision. Scan with the app’s camera tool, or enter the payload manually if a camera is unavailable. A match does not prove that the real-world installation is the correct product.

Photographs and offline use

Use the device camera, Photos picker or file import where supported. Add notes and link evidence to an asset or field. Approved photographs appear in reviewed packages; pending ones are excluded.

For offline use, download the IFC and any images to local storage before disconnecting. Save the export to a local Files location; a cloud location may need connectivity.

Frequently asked questions

Why does my IFC not import?

Check the .ifc extension, supported IFC2X3/IFC4 schema, completed local download and 50,000,000-byte limit. Try another valid export if the file is malformed.

Why does an asset show “Source placeholder” or “Source needs review”?

Values such as n/a and certain 1900-era placeholder dates are retained for provenance but do not automatically count as useful completed values. Inspect the original IFC property and enter the real field information where known.

My QR code is rejected—what should I do?

Open the IFC collection used to create the label. The QR includes a model-qualified identity and file digest. A label from another model, changed file or unknown component is deliberately rejected.

Why are some photos missing from the ZIP?

Only approved evidence is included. Open Review and approve the intended photograph independently. Check package counts before export.

Will the export update my IFC or COBie model?

No. Asset Capture exports reviewed values and evidence for a receiving team. The Receiving view can compare a package with a reference IFC and flag conflicts; it does not edit the reference model.

How can I remove local data?

Open the collection management controls, review the confirmation and delete the selected collection. This removes the app-managed project data and associated evidence for that collection; it does not delete the original IFC selected from Files or exports saved elsewhere.

What does “Capture guidance” do?

It provides built-in offline instructions. It is not connected generative AI and does not send questions to an external model.
